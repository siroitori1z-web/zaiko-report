### 何を作ったか

`subtitle_timing_editor.html` の中にある「画面に依存しないロジック」を、依存ゼロの
ESモジュール群として切り出し・作り直したもの。DOMに触れないので、ブラウザでも Node でも動く。

| モジュール | 役割 | 本体での対応箇所 |
|---|---|---|
| `timecode.js` | 秒⇔フレーム⇔SMPTEタイムコード⇔SRT時刻の変換。既定 30fps non-drop。29.97/59.94 のドロップフレームも対応 | 時刻表示・時刻入力欄・スナップ |
| `srt.js` | SRT の読み込み・書き出し。`（要確認）` を読み込み時にフラグへ変換し、書き出し時は付けない。`_corrected` 名の生成 | 読み込み・上書き保存・別名で書き出し |
| `cues.js` | 並べ替え（安定ソート）・移動・端の調整・追加・削除・番号の振り直し・再生位置の字幕の判定・全体のずらし | I/O キー、ブロックのドラッグ、`resortCues()`、`addCue()`、`deleteCue()` |
| `split.js` | 分割（カーソル位置／再生位置／比率、句読点優先、サロゲートペアを割らない、両側に1フレーム以上） | ✂ 分割 / Ctrl+K |
| `history.js` | 字幕ごとの固定IDで管理する取り消し/やり直し。連続入力を1件にまとめる | Ctrl+Z / Ctrl+Shift+Z |
| `editor-store.js` | 上記をまとめた状態管理（選択・ドラッグのプレビュー・空の追加の取り消し・再生への選択追従など）。UI は `subscribe` で再描画するだけ | 画面全体の状態 `S` |
| `validate.js` | 終了<開始・長さ0・重なり・空テキスト・動画尺超え・短すぎ・要確認の検出、動画とSRTのペア違いの簡易検出、納品前チェック | 警告表示、`finalize_srt.py` 相当の検査 |
| `sequence-map.js` | 元素材時間 ⇔ カット後シーケンス時間の変換（outward 丸め、カット区間内はカット点に寄せて警告）。無音JSONの読み込み、「1秒残し」方式 | `map_to_sequence_time.py` / `map_full_srt_lines.py` の変換部分 |
| `keybindings.js` | ショートカットの対応表（19アクション×最大2キー）、衝突の検出、日本語変換中は反応しない、保存・復元 | ⌨ ショートカット設定 |
| `autosave.js` | 自動保存（保存先は差し替え可能・例外を出さない）。旧形式（`deleted:true` 行、`{i,start,end,text}` の差分形式）も読める | 自動保存と復元 |

### 確定・踏襲した仕様（本体の経緯から）

- **30fps non-drop が既定**（29.97 を使うと7分で約13フレームずれるため）
- フレーム変換は **1ms の許容幅つき**。SRT のミリ秒丸めで境界よりわずかに後ろになる時刻
  （例: 19.042s）を正しく同じフレームとして扱う。表示判定は「開始フレーム ≤ f < 終了フレーム」
- 区間の丸めは **outward**（開始=切り捨て、終了=切り上げ。のりしろを削らない）
- シーケンス時間への変換では、**カット区間の中の時刻はすべて「カット点」1点に寄せる**
  （シーケンス上ではカット区間は長さ0になるため）。区間の終わりちょうどの時刻は区間の終わりとして扱い、
  1フレーム欠けない。字幕がまるごとカット区間に入った場合は長さ0として残し、警告を出す
- 「1秒残し」（`keepSilenceSec` / `keepTailRatio`）: 本体の自動編集 段階12 の確定仕様に合わせ、
  無音区間が keep 秒以下ならそのまま全部残す。keep 秒より長ければ、カット点の前後に**非対称**に
  keep 秒ぶんだけ残す：直前の発話の直後に `keep * keepTailRatio`、直後の発話の直前に
  `keep * (1 - keepTailRatio)`（既定 `keepTailRatio = 0.7` → 1.0秒残しなら 0.7秒/0.3秒。
  `keepTailRatio: 0.5` を渡せば旧来の keep/2・keep/2 の対称分割を再現できる）。
  動画の頭（最初の発話より前の無音）は `keep * (1 - keepTailRatio)` 分だけ発話の直前を残し
  （無音区間がそれより短ければ全部残す）、動画の末尾（最後の発話より後、`videoDuration` 指定時のみ）は
  `keep * keepTailRatio` 分だけ発話の直後を残す。フレーム数は
  `round(keep*fps*keepTailRatio)` と「残り（`round(keep*fps)` から引いた分）」で計算し、
  必ず合計が `round(keep*fps)` フレームちょうどになるようにしている
  （例: keep=1.0秒・24fps は合計24フレームで、17/7 に分割）。

### 確認結果（クラウド環境・Node v22、生成したダミーデータで実施）

- 単体テスト **145件すべて成功**（`cd subtitle-editor && npm test`、外部ライブラリ不使用）
- デモ（`npm run demo`）: サンプルSRT（要確認・空テキスト・長さ0・重なり・終了<開始 を含む8行）を
  読み込み → 検証（エラー1・警告4）→ 分割・追加・削除・取り消し・やり直し → 書き出し →
  ダミーの無音データでシーケンス時間へ変換（通常カット 14.50秒 / 1秒残し・0.7/0.3分割 15.80秒）まで通しで成功
- 実際の素材（tukimi / test01 の動画・SRT・無音JSON）では**まだ試していない**（クラウド環境に無いため）
